# PLAN — light/dark toggle, Patterns page charts with actions

## Goal
1. A theme toggle in the signed-in top bar that cycles System → Light → Dark, remembers the choice, and overrides the OS setting.
2. Replace the Patterns page's basic visuals with charts that each end in a concrete suggestion (pace vs. last month, what changed, when spending happens, what to try next), built from the data the page already loads.
