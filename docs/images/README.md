**How to refresh**

1. Open [p2p-ledger-pi.vercel.app](https://p2p-ledger-pi.vercel.app) (or local `npm run dev:stack`).
2. **F2 ONBOARD** or resume a saved wallet.
3. Full-page screenshot; save under `docs/images/` and commit.
